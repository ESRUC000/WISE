# WISE Windows executable

`WISE.exe` is the single-file, windowed Windows build of the WISE desktop application. It was generated from the repository source with `build_exe.ps1` and PyInstaller. Launch it on Windows; a separate Python installation is not required.

WISE reads the Wi-Fi connection reported by Windows and saves assessment history locally in `%LOCALAPPDATA%\WISE\wise_scans.db`. Review the project README for feature, privacy, and build details.
