# WISE Windows executable

`WISE.exe` is the single-file, windowed Windows build of the WISE desktop application. It was generated from the repository source with `build_exe.ps1` and PyInstaller. Launch it on Windows; a separate Python installation is not required.

WISE reads the Wi-Fi connection reported by Windows and sends account and assessment data to the configured WISE API server. Configure `WISE_SERVER` for the API endpoint; the server stores history in its configured database. Review the project README for feature, privacy, and build details.
